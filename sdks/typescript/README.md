# TypeScript Integration SDK

首个可运行的 TypeScript SDK，当前提供：

- Integration Manifest v1 类型与常量；
- 基于 JSON Schema 的运行时校验；
- `validateIntegrationManifest` 结果式 API；
- `assertIntegrationManifest` 类型收窄 API；
- detect、inspect、plan、apply、verify、rollback 生命周期类型；
- Manifest 基础契约测试。

生命周期接口、change plan、contract test harness 和 mock 工具将在后续迭代加入。
